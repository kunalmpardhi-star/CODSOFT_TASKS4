# CodSoft Task 4 – Contact Book

## 📌 Project Overview

This project is **Task 4 of the CodSoft Python Programming Internship**.

The **Contact Book Application** is a Python-based application that allows users to store and manage contact information in an easy and organized way.

## 🚀 Features

* Add new contacts
* View saved contacts
* Search contacts
* Update contact details
* Delete contacts
* Store name, phone number, email, and other details
* Simple and user-friendly interface

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – Graphical User Interface
* **SQLite3** – Database management

## 🎯 Objective

The main objective of this task is to develop a simple application for managing contact information while improving Python programming and database management skills.

## 📚 Learning Outcome

Through this task, I learned:

* Python programming
* GUI development using Tkinter
* Database management using SQLite
* CRUD operations
* Searching and managing data
* Event handling
